## 💡 What's Happening Under the Hood

### The Simulation Engine
```
1. Builds graph of tree connections
2. Calculates baseline connectivity (82%)
3. Removes Tree #21 from the network
4. Recalculates connectivity (56%)
5. Identifies broken corridors
6. Returns impact metrics
```

### The Technology
- **Frontend**: Next.js 16 + React + TypeScript
- **Backend**: PostgreSQL + Drizzle ORM
- **Maps**: Leaflet + OpenStreetMap
- **Analysis**: Custom graph-based connectivity algorithm
- **Styling**: Tailwind CSS + Framer Motion
